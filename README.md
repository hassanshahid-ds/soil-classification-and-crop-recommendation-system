# Soil Classification and Crop Recommendation System

This project presents a Deep Learning based Soil Classification system and a Machine Learning based Crop Recommendation system.

## Project Components
1. Soil Classification using soil image dataset
2. Crop Recommendation using soil nutrient dataset

## Files in Repository
- Research_project.ipynb : Complete project implementation
- Crop_recommendation.csv : Dataset for crop recommendation
